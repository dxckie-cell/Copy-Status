# Copy-Status

A Revenge / Bunny / Kettu plugin by dxckie cell. It lets you long-press a user's custom status on their profile to select and copy the text, the same way CopyBios does for bios.

## Install

Paste this URL into your Discord client's Plugins page:

> https://dxckie-cell.github.io/Copy-Status/CopyStatus/

(Requires GitHub Pages to be set to deploy from the `gh-pages` branch after the first workflow run.)

## Usage

Open a profile, long-press the custom status bubble, then select and copy the text.
